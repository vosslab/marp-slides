## What it contains

The repository is primarily a README catalog of Marp tools, themes, integrations, examples, and
learning resources. It also contains catalog artwork and package-lint configuration. It does not
provide a renderer, converter, Python functions, or a reusable theme.

## Reuse assessment

- Ideas: Its categorization can help identify future projects for a bounded comparison.
- Code and functions: None are relevant to the local pipeline.
- Themes and assets: Linked themes and tools retain their own licenses. Their appearance in this
  CC0 catalog does not grant permission to copy them.
- Documentation: Catalog text can be reused under CC0, but a local link list would quickly become
  stale and is not needed.

## Decision

Treat Awesome Marp as a directory, not an implementation. Any promising linked project still
requires its own license, code-quality, accessibility, and architectural review before use.
